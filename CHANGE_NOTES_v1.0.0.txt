3. ANTI-ABUSE SYSTEM — FULL BREAKDOWN (15 layers, now visible)
================================================================================
Rate Limiting:
  1. Daily Limit — 1 report / player / IP / 24h (live HH:MM:SS)
  2. Monthly Limit — 2 reports / player / IP / 30d
  3. Velocity Check — Max 5 reports / IP / hour
  4. Org Cooldown — 3-6 reports / org / 24h, scales with org size (tiny 3, small 4, normal 6, large 5)

Retaliation & Brigading Prevention:
  5. Retaliation Cooldown — 7-day block on mutual reports
  6. Mutual Report Detection — Flags within 24h, weight 0.1x
  7. Org Mutual Threshold — ≥5 members of same org report same target → weight 0.5x

Trust & Weighting:
  8. Reporter Weight — New 0.5x, +0.05 per report up to 1.0x
  9. Reporter Reputation — High toxic reduces influence
  10. Org Size Normalization — Larger orgs stricter

Context & Validation:
  11. Disposition Notoriety — 5 hostile → 14-day friendly cooldown
  12. Disposition Consistency — Hostile/friendly tags cannot mix (400)
  13. Activity Validation — Must have been active in-game within 24h (Game.log mtime)
  14. Self-Report Block — Cannot report own handle (client+server)
  15. Score Decay — 2%/month after 6 months inactivity; fresh reports reset

UI Surfacing:
  - Report button instantly disables with live countdown + verbose tooltip
  - check-rate-limit now returns reason + reasonDetail (DAILY_LIMIT, RETALIATION, VELOCITY, ORG_LIMIT, MONTHLY_LIMIT)
  - App logs every block with reason | detail | cooldown | monthly

5. BUG FIXES & STABILITY (vs beta)
================================================================================
Critical Crashes Fixed:
  - QPainterPath NameError flood → restored QPainterPath/QBrush + isVisible guards
  - OCR `'>' not supported str/float` → cast conf to float
  - QThread: Destroyed while still running → removed parent, fixed early `= None` clearing while running, queued next handle via singleShot(0), added deleteLater + finished-clear lambdas
  - Double WELCOME → main_window sets _welcome_sent in both paths + status_bar deduplicates
  - ImageDownloader pool saturation → capped to 6 threads, waitForDone(3000) on exit
  - Resize lockup → eventFilter checks geometry != parent rect before setGeometry; resizeEvent no longer sets geometry
  - Org click no animation → controller _start_org_scrape emits RETRIEVING ORG
  - Player not-found infinite loop → 8s timeout + hide on NOT FOUND
  - Rep disabled despite enabled → status_bar initial sync + reputation_tab showEvent re-sync

Notification Queue:
  - All status_push now short badge + verbose tooltip (OCR ERROR, REPORT FAILED, RETRIEVING DOSSIER, SEARCHING ORG, etc.)
  - Failed scrape now "Player {handle} not found" (simple)

Performance:
  - Removed blocking Game.log I/O from main thread (welcome, is_self checks now non-blocking)
  - Throttled AnimatedProgressBar 60fps→30fps
  - Limited concurrent image downloads
  - Reduced hotkey/pulse timers where possible
